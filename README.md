# RomsDownloader
Gestor de descargas para ROMS de la consola R36S
colocar instalador.sh en /roms/tools ó /roms2/tools según el caso, al ejecutarlo instalará las dependencias necesarias (curl, wget, unzip y lynx) y descargará el script (downloader.sh)

Usa un navegador en modo texto, este permite navegar en myrient.erista.me y poder descagar archivos desde la misma consola.
- A ó B para abrir links
- D-Pad para moverse entre links (izq. retrocede)
- Situarse sobre un link y pulsar X para descargar
- La ROM (ZIP) será descomprimida en /roms/00_DOWNLOADS ó /roms2/00_DOWNLOADS si se ocupa una segunda tarjeta.


Download manager for ROMs on the R36S console: place installer.sh in /roms/tools or /roms2/tools as appropriate. When run, it will install the necessary dependencies (curl, wget, unzip, and lynx) and download the script (downloader.sh).

Use a text-based browser; this allows you to navigate myrient.erista.me and download files from the console itself.
- A or B to open links
- D-Pad to move between links (left to back)
- Hover over a link and press X to download
- The ROM (ZIP) will be unzipped to /roms/00_DOWNLOADS or /roms2/00_DOWNLOADS if a second card is used.
